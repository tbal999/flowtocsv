    Run unattended (SSIS, Task Scheduler, cron)

    The command below runs once with no web page. It converts every file in the inbox that matches saved instructions, writes the output folder, moves the inputs away and exits. Exit code 0 means everything converted, 3 means some files were rejected (the rest were written), and 1 means a fatal error. In SSIS, use an Execute Process Task with Executable set to flowtocsv.exe and Arguments set to everything after it.
